## 如何理解“验证过”

- **M：真实模型**。真实 Hermes 会话、真实模型响应、原生工具和文件副作用。
- **H：原生宿主链路**。运行真实 `AIAgent`、插件加载器、Node 进程、工具执行器或生命周期 hook；
  显式构造调用，不调用模型，不替换工具实现。验证 hook 的项目不冒充完整模型会话。
- **E：真实引擎进程**。真实文件和扫描工作线程，直接调用扫描服务，不经过宿主会话。
- **W：真实 Web 服务/浏览器**。隔离配置目录、真实 HTTP 和 Chrome 页面操作。
- **A：自动化集成/单元测试**。部分测试替换最后的工具执行器或时钟；不算完整真机执行。

本轮工具矩阵包含 **36 个 H 断言场景，全部通过**，另有 **1 个回环访问观察场景**。
真实模型矩阵尝试了 **28 个场景**；模型提前拒绝、改变调用顺序或未生成目标输出的项目
在下面单独标注：19 项达到场景目标、3 项仅部分证据、6 项未触发目标操作。
不能把脚本布尔值当作“28 项端到端防护全部通过”。另有真实 CLI 4 项断言、

## 安全措施

所有读写、删除、符号链接、记忆和插件配置操作均指向新建的 `/private/tmp/aegis-*`
测试目录。命令即使漏拦，也最多改变可丢弃的 canary 文件；管道执行仅打印/写入固定测试标记。
外传使用合成密钥和 `127.0.0.1` 接收端，未接触云元数据、内网服务或真实敏感文件。
技能、来源追踪和编码样例中的危险文本只作为数据读取，从未执行。

真实模型通过 Hermes 原生凭据解析器使用现有授权；凭据未写入测试报告或提交。
仅在合成密钥的隔离测试进程中设置 `HERMES_REDACT_SECRETS=false`，以避免 Hermes 更早的
脱敏层遮挡 AgentAegis 的观测。这不是生产配置变更。未修改用户日常 Hermes/OpenClaw profile。

## 本轮发现并修复

1. **内联路径漏拦**：初始 `node -e` 用例实际改写了可丢弃的受保护 canary。
   shell 分词将整段 `fs.writeFileSync(...)` 当成一个参数，未提取内部路径。
   现在在长度预算内检查代码字面量，识别常见转义路径及绝对/带版本解释器名称；不执行代码求值。
   修复后的 H/M 用例均阻断，canary 保持原值。任意动态构造路径仍不是静态检测的保证范围。
2. **编码工具结果漏检**：Hermes 的 `N|` 行号和 JSON 转义可破坏候选边界；
   原工具结果规则还漏掉 `ignore all previous instructions` / `disable all safety`。
   现在将非编码字符作为分隔符，扩展常见措辞。五类编码的 H/M 复测及回归通过。

最初的失败记录保留在本机临时结果目录，未删除或改写成通过记录。测试过程中另修正了
两个测试前提：上游 Hermes 已提前脱敏；清理断言误把安全警告中引用的 token 名称当成载荷。
TTL 首次测试还遇到 Hermes 重复结果引用，预算首次测试遇到宿主单行截断，
随后使用不同密钥和多行文件建立了有效前提并复测。这些前提修正与上述产品缺陷区分记录。
