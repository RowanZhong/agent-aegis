# 误报优化与验证（2026-09-18）

本轮针对可明确界定的误报和重复告警做小范围修复。Hermes 支持范围仍为
**v2026.8.19**（`fcbd1076a93841fa88855acce810e342a5b78101`），不恢复新版兼容，
也不需要设置 `plugins.hook_callback_timeout: 0`。

## 行为变化

| 场景 | 原行为 | 本轮行为 | 保留的防护 |
| --- | --- | --- | --- |
| 工具结果仅命中 `secret-request` 弱关键词，例如文档提到 token、cookie、env | warning | 无其他风险、真实敏感值、特殊角色标记或超限时，降为 info；页面显示“信息” | 仍扫描、记录审计并保留风险上下文；更强证据仍为 warning |
| 同一会话、工具返回完全相同的风险内容 | 每次重复警告 | 首次照常提醒，窗口内重复项记 debug，在回合/会话结束等时机输出计数摘要；页面默认合并显示 | 每次重新扫描、写入独立 JSONL 事件；不缓存放行决定，不合并阻断事件 |
| Node/Python 仅打印一个包含受保护路径的字符串 | 被内联路径规则误当作访问文件 | 完整命令满足下述严格语法时，豁免内联字符串路径检查 | 其他工具调用防护仍执行；真正读写、重定向、管道和附加语句不获得该豁免 |
| 用户请求中同时出现 `terminal` 和受保护路径 | `terminal` 中的 `rm` 被当作删除意图，整轮拒绝 | 英文破坏性动词按单词边界匹配；`terminal`、`normal`、`format`、`confirm` 不再命中 `rm` | `rm`、`/bin/rm`、`delete`、`remove` 及相关词形、中文删除/覆盖等仍匹配 |

纯打印豁免示例：

```sh
node -e 'console.log("/protected/example.txt")'
python3 -c 'print("/protected/example.txt")'
```

识别器只接受完整命令：解释器名（或简单绝对路径）、对应的 `-e` / `-c`、
**POSIX 单引号包裹的程序**，程序只能调用一次 `console.log` / `print`，
参数只能是一个 JSON 双引号字符串，可带末尾分号。命令上限为 8192 字符；
不接受实际换行、环境变量前缀、额外参数、模板字符串、表达式、其他语句、
管道或重定向。不执行代码进行判定，也不因内容被截断而放行。

这是语法子集识别，不是任意 JavaScript/Python 的安全分析或执行沙箱。
宿主继承的解释器启动环境、预加载代码和同名程序仍属于宿主可信边界。
不在子集内的代码继续走现有规则；不承诺所有合法纯打印写法均可放行。

## 重复告警边界

- 分组由会话、工具、严重级别和原始扫描文本的 SHA-256 等信息共同确定。
  只保存摘要与计数，不在分组表中保留内容。
- 固定 5 分钟窗口从首次命中算起，后续命中不延长窗口；最多保存 256 组。
  到期后再次命中会重新提醒，淘汰分组及结束会话时结算待报告计数。
- 超限或扫描不完整的内容不合并，内容变化、工具变化和会话变化也不合并。
- 只合并 `tool_result_scan` 的 `observed` 通知。阻断操作每次检查、每次记账、
  每次在页面单独显示。其他类型的告警不受此优化影响。
- Web `/api/events` 默认仍返回原始记录，只有 `collapse=true` 才合并，且先合并再分页。
  页面可取消“合并重复告警”。计数仅表示服务当前加载的记录（现有上限 1000 条），
  不代表整个历史日志；磁盘 JSONL 不删减。
- WebUI 仍是 OpenClaw 配置编辑器。本轮展示测试只读取从临时 Hermes 环境复制出的
  审计数据，不能用它编辑 Hermes 的 YAML 配置。

真实模型首轮验证**未通过**：`terminal` 中的 `rm` 触发了原有的整轮拒绝。
因此追加了单词边界修复与 14 个正反例，再运行完整自动化/集成检查和真实模型会话，
最终全部通过。此前真工具、HTTP 捕获与 Web 夹具检查覆盖的路径不依赖该词边界修改；
最终模型和集成测试覆盖了修改后的前置判定。

本轮没有重新跑此前整套全部能力真机矩阵；历史结果及其验证层次仍以
[能力覆盖表](live-coverage-2026-09-18.md)为准。

## 尚未解决

引用攻击语句进行教学、否定句、合法安全分析等语义场景仍可能误报。
例如教程引用“忽略之前的指令”仍按强风险处理；本轮没有凭引号或“这是示例”放行。
也没有新增模型裁判、域名全局白名单或自动学习放行。

本轮能减少指定误阻断和告警噪声，不能据此宣称整体误报率或漏报率下降了某个百分比。
新增逻辑使用有界解析、哈希及内存分组，不引入外部模型调用或运行时依赖；
存在少量本地计算开销，未进行吞吐量基准测试。
